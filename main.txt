Очередные изменения

git init - инициализация локального репозитория

git add <file> - добавление файла к отслежтванию
git add . - добавление всех файлов

git commit -m "message" - коммит с сообщением

git remote add origin <ссылка на github> - подключение к удаленному репозиторию

git push origin <название ветки> - отправление на удаленный репозитоирий

git clone <ссылка на github>
